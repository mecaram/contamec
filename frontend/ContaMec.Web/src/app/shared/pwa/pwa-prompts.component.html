Hay una nueva versión de ContaMEC

Instalá ContaMEC en este dispositivo para abrirla como una app. Para instalar ContaMEC, tocá Compartir ios_share y luego «Agregar a pantalla de inicio». Para instalar ContaMEC, tocá Compartir ios_share en el navegador y luego «Agregar a pantalla de inicio». Si no aparece, abrí ContaMEC en Safari. Para instalar ContaMEC, elegí Archivo › Agregar al Dock. Para instalar ContaMEC, abrí el menú more_vert y elegí «Instalar» o «Agregar a pantalla de inicio». ContaMEC funciona igual desde este navegador. Para instalarla como app, abrila en Chrome, Edge o Safari.

Sin conexión

ContaMEC necesita internet para mostrar los datos contables actualizados. Cuando vuelva la conexión, la pantalla sigue donde estaba.
