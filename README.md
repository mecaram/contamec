# ContaMec

Aplicación fullstack para gestión contable diaria.

## Tecnologías utilizadas

- Angular
- ASP.NET Core
- Entity Framework Core
- SQL Server

## Estructura

```text
ContaMec/
  backend/
    ContaMec.Api/
  frontend/
    ContaMec.Web/
```

## Cómo ejecutar

### Backend

```bash
cd backend/ContaMec.Api
dotnet restore
dotnet run
```

### Frontend

```bash
cd frontend/ContaMec.Web
npm install
ng serve
```
